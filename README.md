# ALLiber — 배포본

**ALLiber 안드로이드 앱의 배포본만 담는 저장소입니다. 소스 코드는 여기 없습니다.**

---

## 받는 법

[**Releases**](../../releases)에서 가장 최근 판의 `.apk` 파일을 내려받아 설치합니다.

처음 설치할 때 안드로이드가 *«출처를 알 수 없는 앱»*을 허락할 것인지 물어봅니다. 브라우저나 파일 앱에 한 번 허락해 주시면 됩니다.

## 이미 쓰고 계신다면

**앱이 스스로 새 판을 알려 줍니다.** 앱이 뜰 때 이 저장소에 새 판이 있는지 묻고, 있으면 서가 위에 한 줄이 섭니다 — 누르면 받아서 설치 화면으로 넘어갑니다.

- 나가는 것은 **그 물음뿐입니다.** 책도, 읽던 자리도, 그은 것도, 메모도 나가지 않습니다
- 설치는 **안드로이드가 다시 확인합니다** — 앱이 조용히 깔지 않습니다
- 원하지 않으시면 **설정 → 자동 업데이트**에서 끌 수 있습니다

## 판 번호

`v0.1.0` 같은 꼴입니다. 앱은 마디마다 수로 견주므로 `0.10.0`이 `0.8.0`보다 새 판입니다.

## 서명

모든 판은 **같은 키로 서명**됩니다. 그래서 새 판이 옛 판을 덮어써도 **서가와 읽던 자리가 그대로 남습니다.** 다른 곳에서 받은 APK는 서명이 달라 덮어쓰이지 않습니다 — 반드시 이 저장소에서 받으십시오.
